## ◉ ABOUT THE PROJECT

This is my personal portfolio — designed and engineered as a **digital workspace** rather than a conventional developer portfolio.

The visual direction combines:

- ✦ Minimal editorial layouts
- ✦ Interactive interfaces
- ✦ Motion & transitions
- ✦ Experimental navigation
- ✦ Stationery-inspired visual elements
- ✦ Clean typography
- ✦ Dark / light visual contrast

The idea was simple:

> **Make a portfolio that feels like stepping into the creator's workspace.**

Every section has its own visual language, interaction and purpose while keeping the overall experience connected.

## 🎨 DESIGN PHILOSOPHY

I didn't want the portfolio to feel like:

```text
Name
↓
Skills
↓
Projects
↓
Resume
↓
Contact
```

Instead, the interface takes inspiration from **physical creative spaces**:

```text
Sketchbooks
Sticky notes
Paper
Editorial layouts
Workbenches
Cards
Grids
Motion
```

The result is a digital portfolio that tries to feel **personal, tactile and alive.**

## 🚀 RUN LOCALLY

Clone the repository:

```bash
git clone https://github.com/Krishna-Ghodake/krishna-ghodake-portfolio.git
```

Move into the project:

```bash
cd krishna-ghodake-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
